# ScanNet++ Learned 3DGS External Qualification V1

This task is an official ScanNet++ v2 learned-3DGS qualification route, not a replacement or reinterpretation of the frozen PR #65 Replica benchmark. It accepts only official dataset/toolbox/demo authority, strict train/heldout isolation, independent official-mesh geometry evaluation, and one official baseline plus the sole conditional metric-depth-supervised variant.
