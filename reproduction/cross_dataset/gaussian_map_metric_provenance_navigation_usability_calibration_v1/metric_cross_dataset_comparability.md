# Metric Cross-Dataset Comparability

A numeric metric is comparable across datasets only when formula, depth convention, target mask, renderer acceptance semantics, aggregation unit, reference authority, spatial domain, and scale are matched. Historical TUM, Replica, and ARKitScenes summaries do not satisfy all of these conditions jointly. Therefore their values are evidence profiles, not a pooled leaderboard or a basis for a universal cutoff. Native/common renderer parity is a separate required record; absence of parity is not permission to select the favorable channel.
