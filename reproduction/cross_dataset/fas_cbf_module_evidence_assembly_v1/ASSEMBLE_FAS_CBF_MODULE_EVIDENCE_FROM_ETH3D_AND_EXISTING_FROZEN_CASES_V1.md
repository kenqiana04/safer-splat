# ASSEMBLE_FAS_CBF_MODULE_EVIDENCE_FROM_ETH3D_AND_EXISTING_FROZEN_CASES_V1

This task freezes a provenance-aware, configuration-bounded evidence package from PR #81 and existing frozen GT-derived, official-map, learned-3DGS, and learned-SLAM case studies.

It permits only read-only source recovery, SHA inventory, deterministic compact-statistic recomputation, and generation of tables, figures, and reports. It forbids new maps, searches, controller rollouts, tuning, dataset changes, map/method mutation, and source-result relabeling.

The decision must be based on module-wise support rather than on an unsupported global Full FAS-CBF superiority claim.
