# Select, Freeze and Package One ARKitScenes Pretrained Gaussian Map with an Official RGB-D / Pose / Mesh Join V1

This tracked protocol implements the bounded ARKitScenes continuation from PR #61. It accepts only the ARKitScenesGS repository resolved by the frozen SceneSplat README; a same-named legacy repository must never be substituted. Before every map or Apple payload download it requires an exact scene/video join, at least 20 exact training-frame joins, and a training-only fixed scale-one SE(3) contract. Sim(3), scale fitting, ICP, preview matching, geometry evaluation, map modification, SAFER, navigation, CBF-QP, and TUM actions are prohibited.

The observed execution gate is component-specific Hugging Face access. All post-access phase artifacts remain explicit `NOT_AUTHORIZED_DUE_TO_BLOCKED_BY_ARKITSCENES_COMPONENT_ACCESS_APPROVAL_REQUIRED` records until an authorized resumed task proves that a non-card lightweight component file is readable.
