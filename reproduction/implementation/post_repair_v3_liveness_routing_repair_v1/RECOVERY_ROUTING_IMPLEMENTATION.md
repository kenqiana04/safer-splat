# Typed routing and priority

The Gate 0 trigger is same-cycle L1 PASS, primary present, primary C0/L2 PASS, typed candidate-local primary L3 FAIL, no valid retained backup, exact state/map/geometry/actuator/transition identities, certified current-state terminal prefetch, deadline OPEN, registered source and eligible exhaustion key. The L3 local allowlist contains only exact nested `BACKUP_SEGMENT_NOT_CERTIFIED` and future-terminal reasons; generic FAIL, UNKNOWN, timeout, immediate-segment, actuator and unmapped reasons are excluded. Identity contradiction routes to typed no-plant boundary.

Recovery-specific rows are resolved by `Supervisor.route_transition`, including deadline admission before each new candidate. Each candidate follows fresh L1 binding then C0→L2→L3. Local FAIL may advance in frozen order; UNKNOWN/global blocks new search. First full PASS is offered to `Supervisor.arbitrate`; a valid retained backup outranks recovery, and a pre-certified terminal follows exhaustion. Existing legacy routing remains the default outside the typed Gate 0 scope. No Coordinator-created `RoutingDecision`, executable action, deadline policy or backup priority exists.
