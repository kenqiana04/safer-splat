# Frozen diagnostic protocol

The frozen posthoc analyzer builds Active states from the first observation `pre_state` and then appends `post_state` only for committed rows. It invokes the frozen conservative segment helper on each adjacent position pair with radius `0.015 q`. The helper evaluates interval midpoints breadth-first. For a finite map result it computes `clearance = signed_distance - 0.015`; the strict predicate is `clearance < 0.0`. There is no safety epsilon or tolerance in this predicate. On the first negative midpoint it returns `UNSAFE`, so the stored negative clearance is a witness, not a segment-global minimum.

The frozen point pipeline constructs segment coordinates in NumPy float64, then the query bridge casts each point to torch float32 on CUDA. The frozen map tensors are loaded as model tensors and are float32. `GSplatLoader.query_distance(..., distance_type="ball-to-ellipsoid", radius=0.015)` rotates the point into every Gaussian frame, solves point-to-ellipsoid squared distance with 25 bisection iterations, applies the inside/outside sign, and subtracts `radius^2`. `SourceGaussianBarrierAdapter` takes the minimum barrier, reconstructs signed distance as `sign(h + radius^2) * sqrt(abs(h + radius^2))`, and the segment helper subtracts the radius.

Runtime L1 and the posthoc oracle concern the same immediate closed position segment `p_k -> p_k + dt v_k` / committed `pre_state -> post_state` under position-first forward Euler dynamics. Runtime L2 concerns the next H1 segment `p_k1 -> p_k2`; L3 certifies a backup witness. Runtime trace stores the committed action and runtime reason, while per-cycle certificate payloads are not serialized there. Same-segment PASS may therefore be inferred only when the frozen runtime reason and source contract jointly establish it, and otherwise is reported as unavailable rather than guessed.

For each unique violating segment, the fixed depth audit uses exactly 1025 samples `t=j/1024`, then four 65-point local-refinement layers. Repeat and ULP audits are fixed at 20 identical queries and seven representable neighbors. There is no radius, epsilon, or PASS-threshold sweep. The optional float64 path promotes the exact loaded Gaussian parameter values and independently recomputes the same formula; it is admissible only if three predeclared sanity points agree within the protocol's arithmetic-parity tolerance. That tolerance is not a scientific gate.

The numerical and runtime classifications are restricted to the enumerations in `DIAGNOSTIC_PROTOCOL.json`. The frozen scientific decision remains `FAIL_V3_HARD_SAFETY_GATE` under every diagnostic outcome.
