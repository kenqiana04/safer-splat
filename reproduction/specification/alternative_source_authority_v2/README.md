# Alternative Source Authority V2

This directory freezes a specification-only provenance and authority contract for alternatives in the SAFER-Splat V2 method chain. It creates no candidate, controller behavior, runtime hook, rollout, benchmark, or scientific evidence.

The sole alternative-search owner is `SUPERVISOR`. L4 may request evaluation of an already lawful candidate; it cannot create, certify, select, or commit a control. V2 default authorization permits only `SOURCE_NATIVE_EXISTING`. Every alternative receives a complete immutable identity and fresh `C0 → L1 → L2 → L3` evidence before Supervisor arbitration.

The L1 step remains candidate-independent. Its inclusion in the alternative chain is a fresh state/time/map-bound evaluation record, not a claim that L1 depends on candidate control and not a new alternative-search trigger.
