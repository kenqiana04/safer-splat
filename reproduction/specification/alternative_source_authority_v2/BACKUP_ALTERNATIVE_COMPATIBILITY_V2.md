# Backup and Alternative Compatibility V2

A backup witness is an L3 certification product, not an alternative source. Its tail controls do not become alternatives merely because the source candidate was an alternative. Conversely, an alternative does not become a valid backup without a complete L3 witness and the later frozen backup-token runtime schema.

If one control object is explicitly presented in both roles, it must preserve the same candidate identity and source provenance and must independently satisfy:

- `CERTIFICATION_GEOMETRY_AUTHORITY_V2` and immutable map authority;
- `NORMATIVE_COMPONENTWISE_ACCELERATION_AUTHORITY_V2`;
- exact state/time alignment;
- fresh C0/L1/L2/L3 evidence;
- the future backup-token identity and temporal-validity schema.

Role conversion cannot create authority, reuse a prior certificate, or bypass deadline gating. This task does not freeze the backup-token runtime schema and does not implement a backup.
