# Backup Terminal Reference Consumption V2

`BACKUP_TOKEN_EXHAUSTED != TERMINAL_ACTION_AUTHORIZED` remains unchanged.

A retained bundle may expose a content-addressed terminal certificate reference, but that reference is evidence only. Before use, the Supervisor must resolve and verify the certificate hash, exact certified terminal state, current cycle/time index, map authority, geometry authority, actuator authority, dynamics/timebase, exact terminal action identity, deadline preparation identity, and an eligible current policy context.

Any mismatch makes the reference ineligible. Historical validity at the end of an L3 witness is not permanent runtime validity. EXHAUSTED alone never selects or commits zero-hold.
