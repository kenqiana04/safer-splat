# Terminal Safety / Liveness Boundary V2

Terminal safety is not navigation success. A zero-hold trajectory can satisfy represented-map terminal evidence while making no progress and never completing the task.

Future evaluation must keep safety, navigation progress, goal/task completion, terminal intervention rate, backup activation rate, and assurance-boundary rate as distinct quantities. This task defines no metric, threshold, estimator, oracle, or performance claim. Those authorities remain for `FREEZE_INDEPENDENT_EVALUATION_ORACLE_V2`.
