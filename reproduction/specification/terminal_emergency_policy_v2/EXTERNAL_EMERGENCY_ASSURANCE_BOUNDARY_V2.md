# External Emergency Assurance Boundary V2

`EXTERNAL_EMERGENCY_AUTHORITY = UNRESOLVED_OUTSIDE_METHOD`.

When no timely certified navigation, no still-valid retained backup, and no eligible current certified terminal action exist, the only method output is `ASSURANCE_BOUNDARY_NO_CERTIFIED_ACTION`. This means the method has no certified executable action and its theorem ends. It is not a physical command and makes no physical safety claim.

Any real external emergency controller belongs to independent outside-method authority until separately specified and proven. Zero control, hold-last, nominal control, desired control, arbitrary braking, solver failure, exception, return, program break, and process termination are not method-certified emergency actions.
