# First Cycle and Start Admission V2

Before any trial, `AuthorityRegistry.verify_all()` must pass. I0a performs the frozen full-query start admission on x0. I0b is invoked only if an existing, separately lawful repair primitive is configured and content-addressed. No such primitive is authorized by this design; therefore the initial profile sets I0b unavailable. An unsafe/unknown initial admission reaches the assurance boundary without a plant action.

The first runtime cycle begins with retained-backup state `NONE`. R0 is diagnostic only. L1 certifies the candidate-independent immediate segment. A first-cycle primary may commit only after C0, L2, and L3 all pass and L3 has prepared an immutable next-cycle bundle. The navigation commit atomically activates that token for k+1. L3 absence/FAIL/UNKNOWN with no old valid token cannot commit the primary and routes to eligible pre-certified terminal or boundary. There is no uncertified first-cycle escape.
