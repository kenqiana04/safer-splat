# Active Runtime Validation Ladder V2

1. **IMPLEMENT_ACTIVE_RUNTIME_ASSURANCE_V2** — code plus unit/static tests only; no official cohort.
2. **VERIFY_ACTIVE_HARNESS_BYPASS_EQUIVALENCE_V2** — small deterministic `REFERENCE_BASELINE` vs `ACTIVE_HARNESS_BYPASS` QA for selected/executed action, state trajectory, branches, identities, and termination.
3. **VALIDATE_ACTIVE_RUNTIME_CONTRACT_CONFORMANCE_V2** — synthetic targeted primary/backup/terminal/boundary/UNKNOWN/deadline branch tests.
4. **ACTIVE_RUNTIME_SMOKE_V2** — separately authorized minimal engineering smoke, with no paper conclusion.
5. **BUG-ONLY CORRECTION** — only implementation defects exposed by smoke; no outcome tuning or contract changes.
6. **FREEZE FINAL ACTIVE EXPERIMENT PROTOCOL** — statistics, manifest, and numeric deadline profile frozen before data.
7. **FORMAL FINAL100 ONCE** — one separately authorized formal execution.

No stage may be skipped. Failure routes to diagnosis/correction at that stage; it does not trigger repeated 100-trial runs.
