# Candidate Certification Pipeline V2

Every primary and every lawful native alternative follows exactly:

`fresh attempt identity -> L1AttemptBinding -> C0 -> L2/H1 -> L3 -> prepared immutable backup bundle -> Supervisor arbitration`.

C0 checks finite exact identity and PR #109 actuator bounds; it never clips. L2 uses PR #108 authority (`controller radius 0.015 m`, margin `0.010 m`, certification effective radius `0.025 m`, G3 immutable represented-map identity, `rho_seg=0`) and the H1 position-first indexing. It cannot import the historical V1 `load_frozen_robot_margin_contract()` or any `0.11 m` authority. L2 PASS establishes only candidate-dependent future represented-map certification, not recoverability or commit authority.

L3 begins only after L2 PASS and may prepare a content-addressed immutable witness bundle. Prepared is not active. A witness becomes the next retained token only after exact source-candidate navigation commit. Candidate-local failures may request bounded L4 only if a valid unaffected retained backup exists, the deadline is OPEN, and native alternatives remain. Global authority/evidence UNKNOWN does not become candidate search. Each alternative restarts C0/L2/L3 with a fresh attempt binding. No layer directly commits.
