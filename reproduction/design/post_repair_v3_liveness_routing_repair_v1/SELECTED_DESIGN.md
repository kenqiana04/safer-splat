# Selected: CERTIFIED_BOUNDED_LOCAL_RECOVERY

## Trigger and certificate

At primary **L3 FAIL with a separately typed candidate-local reason**, Supervisor may first route a current-state terminal certificate *before* recovery search, only when same-cycle L1 PASS, no valid retained backup, OPEN deadline, exact map/geometry/actuator/canonical state identity, source authority registered, and the exact numerical state/authority/library key has not already exhausted recovery. The existing runtime does not yet expose per-attempt L3 FAIL reason/scope in its formal trace: future implementation must add a deterministic typed reason/scope carrier before enabling this branch. Unclassified FAIL is not presumed local and keeps the frozen fallback. A terminal PASS is cached for this snapshot and provides a certified fallback; terminal FAIL/UNKNOWN routes boundary and recovery does not start. Global authority/identity UNKNOWN blocks; no recovery on C0/L2/L3 UNKNOWN. A retained valid backup always keeps frozen priority.

The recovery provider supplies at most six deterministic candidate vectors: +x, −x, +y, −y, +z, −z at the respective frozen actuator bounds, with all other components zero. Exact duplicate or zero vectors are removed. This is a *new* `SOURCE_BOUNDED_LOCAL_RECOVERY_V1` requiring explicit prospective authorization; it is not silently relabeled `SOURCE_NATIVE_EXISTING`. There is no goal-conditioned order, randomization, interpolation, waypoint, path planner, outcome-conditioned generation or learned weight.

For each candidate, reuse the one authoritative L1 cycle result, create a fresh attempt binding and C0 provenance admission, then L2/H1, then canonical L3 finite braking/terminal witness. The first candidate with full PASS and matching prepared bundle may enter Supervisor arbitration; an uncertified candidate can never reach PlantCommit. If the deadline ceases to be OPEN or all six candidates fail locally, stop the scan; Supervisor selects the prefetched certified terminal when still valid for the exact snapshot, otherwise boundary. `SOURCE_INVALID`, provenance/identity error, or global/unknown certificate scope blocks; none is converted to an ordinary local failure with another attempt. No terminal action is declared unsafe.

## Boundedness and re-entry

The recovery opportunity is one public cycle; it is **not** a multi-cycle recovery mode. Its horizon is the existing L2/H1 two-step causal point plus the existing finite L3 braking witness; no new horizon value is chosen. A trial-local, monotone exhausted-key register prevents rerunning the same six candidates at an unchanged canonical **numeric** state, map/geometry/actuator/transition/library authority and goal context. Snapshot identity includes cycle index and is not the fixed-point key. New numerical state or authority requires a fresh decision, but all prior certificates are discarded and primary L1/P0/C0/L2/L3 is run again. The register is a search-suppression fact, never action authority.

The selected action, if any, uses the existing alternative-navigation role and L3 prepared bundle, then existing ActiveRunner/PlantCommit/token/trace. Subsequent primary navigation re-entry requires fresh certification at the new snapshot. If the local library cannot obtain a full L3 witness, the design provides no liveness gain; terminal/boundary remains authoritative. Formal85 outcomes are never used in runtime triggers or candidate selection.
