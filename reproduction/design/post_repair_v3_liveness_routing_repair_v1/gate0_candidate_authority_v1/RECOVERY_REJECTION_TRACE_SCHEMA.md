# Additive per-candidate rejection trace V1

Future implementation emits one append-only attempt record at each candidate resolution, and one scan-close record. Required **NORMATIVE_EVIDENCE** fields: `trial_id`, `cycle_id`, `recovery_scan_id`, `exhaustion_key`, `candidate_rank`, `candidate_id`, `candidate_source`, `generator_version`, `canonical_action_identity`, `source_state_identity`, `numeric_state_bits_hash`, `map_identity`, `actuator_identity`, `hard_geometry_identity`, `C0_status/reason/evidence_id`, `L2_status/reason/evidence_id`, `L3_status/reason/reason_scope/evidence_id`, `deadline_observations` at entry, candidate-stage and commit guards, `candidate_final_disposition`, `selected`, `selected_by_supervisor`, `rejected_by_stage`, `fallback_reason`, `prepared_bundle_id` if PASS, `SupervisorDecision_id`, `trace_outcome_id`. Unreached layers are `NOT_REACHED`, never fake PASS/UNKNOWN. Each reason preserves the underlying frozen code plus additive recovery wrapper.

Typed dispositions: `RECOVERY_C0_FAIL`, `RECOVERY_C0_UNKNOWN`, `RECOVERY_L2_FAIL`, `RECOVERY_L2_UNKNOWN`, `RECOVERY_L3_FAIL`, `RECOVERY_L3_UNKNOWN`, `RECOVERY_IDENTITY_MISMATCH`, `RECOVERY_DEADLINE_BLOCKED`, `RECOVERY_DUPLICATE_SKIPPED`, `RECOVERY_CERT_PASS`. Missing normative record marks existing execution evidence ineligible according to trace/commit atomicity; it must not initiate retry, change candidate order or change action. Convenience counts/timing summaries and text explanation are **DIAGNOSTIC_ONLY**. Per-candidate L3 FAIL reason/scope is currently absent in formal trace; future typed carrier must be installed before enabling this source.

Trace writer has **zero routing, action-selection, deadline, certificate or PlantCommit authority**. Reuse existing trace/commit atomicity. A selected candidate's trace must bind exact candidate, bundle, Supervisor decision and PlantCommit receipt; failure is handled by the existing evidence/recovery boundary, never `except: execute nominal`. No scientific progress or NI metric enters routing records.
