# Exact F1 generator

Input `U_rec(x_k,authority,typed_runtime_facts)` consumes only: immutable same-cycle snapshot identity; its canonical numeric-state bytes (for exhaustion); exact map/goal/dt identity; frozen 3D componentwise actuator authority; source/generator version; typed Supervisor entry grant. It does not consume trial ID as a *directional* input, previous outcomes, map-query values, current certificate margins or goal direction. Trial/cycle IDs remain provenance on the emitted candidate because the existing runtime identity contract requires them.

Precondition: all authority endpoints finite; three dimensions; each interval contains exact zero; `low_i<0<high_i`; frozen stack uses `(-0.1,-0.1,-0.1)` and `(0.1,0.1,0.1)` in q acceleration coordinates. If not, return typed `RECOVERY_SOURCE_AUTHORITY_UNSUPPORTED`, zero candidates, no clipping or invented replacement. General asymmetric intervals that straddle zero are permitted, using each signed endpoint directly.

For ordered directions `(+x,-x,+y,-y,+z,-z)`, construct exactly `(high_x,0,0)`, `(low_x,0,0)`, `(0,high_y,0)`, `(0,low_y,0)`, `(0,0,high_z)`, `(0,0,low_z)`. No normalization, scaling, random draw, interpolation, optimization, post-generation clipping or map query. Each vector is converted to the canonical float32 transition-control representation **before** vector-equivalence dedup; nonfinite/zero after conversion is a typed source failure or skip, never an uncertified action. Exact endpoint equality to frozen bounds is allowed by inclusive actuator contract.

Dedup: canonical vector identity is SHA256 of dimension=3, three normalized-zero IEEE-754 binary32 bit patterns and canonical transition/actuator identity. Signed zero normalizes to positive zero under the frozen numerical transition equivalence; no epsilon. Compare also with the already formed primary candidate's canonical vector identity, and skip equal recovery vectors; preserve earliest generator rank. `SelectedAction.identity` cannot serve this purpose because it includes role/source/certificate references. The candidate emitted for every retained vector must use future authorized source, `CandidateRole.ALTERNATIVE`, creation timestamp, exact snapshot state/map and controller identity via existing `make_candidate` semantics. The generated `candidate_id` is that resulting `CandidateIdentity`; source, rank and canonical vector hash are separately logged. At most M=6 retained vectors.

Every retained vector: fresh L1 attempt binding from the **same** current-cycle candidate-independent L1 PASS, then C0, L2/H1 and canonical L3. No reuse of a different candidate's C0/L2/L3 result. Candidate PASS requires L3 PASS and matching prepared bundle. L3 FAIL/UNKNOWN cannot commit. L1 is never re-evaluated per recovery candidate. The first full PASS is proposed to `Supervisor.arbitrate`, not executed by the provider/coordinator.
